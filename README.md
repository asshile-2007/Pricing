# Pricing:-

 # Description:-
 ** House Price Prediction Test Model Based On Boston Dataset :- 

A machine-learning web application that predicts house prices using
Flask and XGBoost.

Features:-
- House price prediction
- Machine learning model
- Flask web interface
- XGBoost
- Deployed on Render

Tech Stack:-
- Python
- Flask
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- HTML/CSS
- Render
